# ERC20 Locker

Upgradeable ERC20 token locker smart contract.

## Overview

Erc20Locker allows users to lock a fixed amount of a predefined ERC20 token for a predefined period.

Features:
- Fixed ERC20 token
- Fixed lock amount
- Fixed lock duration
- One active lock per user
- Withdraw after unlock timestamp
- OpenZeppelin AccessControl
- Proxy upgradeable design

## Security

The contract was reviewed and audited.

## Tech Stack

- Solidity 0.8.24
- Hardhat
- OpenZeppelin Contracts Upgradeable v5.0.2
